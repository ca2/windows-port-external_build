FFmpeg — Windows x64 Build Dependencies

Host tools checked by port/external_build/ffmpeg/CMakeLists.txt when building FFmpeg for Windows x64.

x64 ARM64

MSYS2 (bash, cygpath, GNU make, diffutils)

Required — MSVC & MinGW x64

FFmpeg's upstream ./configure and Makefiles require an MSYS2 POSIX shell environment (including /usr/bin/bash, /usr/bin/cygpath, /usr/bin/make, and diff), even when compiling with MSVC.

Open MSYS2 Download Page
  1. Under Installation on the MSYS2 homepage, click Download the installer (msys2-x86_64-*.exe).
  2. Install to the default directory (C:\msys64) so C:/msys64/usr/bin/bash.exe is found automatically.
  3. Open the MSYS2 terminal and install GNU make and diffutils: pacman -S make diffutils.

Checked by CMake: bash.exe in PATH or C:/msys64/usr/bin, with cygpath.exe, make.exe, and diff.exe in the same directory.

NASM Assembler (win64)

Required — MSVC x64

FFmpeg x64 builds use nasm (or yasm) for x86-64 SIMD assembly unless --disable-x86asm is passed.

Open NASM Download Page
  1. Click Download, open the latest stable release folder, and open win64/.
  2. Download and run nasm-*-installer-x64.exe (or install via MSYS2: pacman -S nasm).
  3. Ensure nasm.exe is on PATH (or in C:\msys64\usr\bin / C:\Program Files\NASM), then restart Visual Studio.

Checked by CMake: nasm.exe or yasm.exe in PATH, MSYS2 /usr/bin, or C:/Program Files/NASM.

Visual Studio C++ x64 Build Tools

Required — MSVC x64

MSVC FFmpeg builds use cl.exe, lib.exe, and link.exe from Visual Studio.

Open Visual Studio Downloads
  1. Download Visual Studio (Community/Pro/Enterprise) or scroll to Tools for Visual Studio → Build Tools for Visual Studio.
  2. In Visual Studio Installer, enable the Desktop development with C++ workload.

Checked by CMake: MSVC C compiler (cl.exe) inside the vcvarsall.bat x64 environment.
