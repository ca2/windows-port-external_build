OpenSSL — Windows x64 Build Dependencies

Host tools checked by port/external_build/openssl/CMakeLists.txt when building OpenSSL for Windows x64.

x64 ARM64

Native Windows Perl (Strawberry Perl — 64-bit x64)

Required — MSVC x64

OpenSSL's MSVC configure script requires a native Windows Perl ($^O == MSWin32). MSYS2 or Git Bash Perl will not work for MSVC builds.

Open Strawberry Perl Download Page
  1. On the Strawberry Perl homepage, choose the Recommended version — 64-bit MSI installer (.msi, not the Portable ZIP).
  2. Run the MSI installer using the default destination directory (C:\Strawberry\).
  3. Restart Visual Studio or your build terminal if PATH was updated, then rebuild.

Checked by CMake: perl.exe in PATH or C:/Strawberry/perl/bin, and perl -e "print $^O" returning MSWin32.

NMake (Visual Studio C++ x64 Build Tools)

Required — MSVC x64

OpenSSL's MSVC makefiles are built with nmake.exe from Visual Studio.

Open Visual Studio Downloads
  1. Download Visual Studio (Community/Pro/Enterprise) or scroll to Tools for Visual Studio → Build Tools for Visual Studio.
  2. In Visual Studio Installer, enable the Desktop development with C++ workload (includes MSVC x64/x86 build tools and nmake.exe).

Checked by CMake: nmake.exe available inside the Visual Studio vcvarsall.bat x64 environment.

NASM Assembler (win64)

Optional — MSVC x64 with OPENSSL_ASM=ON

Only required if you explicitly enable -DOPENSSL_ASM=ON when building OpenSSL x64 with MSVC.

Open NASM Download Page
  1. Click Download, open the latest stable version folder, and open win64/.
  2. Download and run nasm-*-installer-x64.exe.
  3. Ensure the NASM install directory is on your system PATH, then restart Visual Studio.

Checked by CMake: nasm.exe in PATH when OPENSSL_ASM is enabled.

MSYS2 (bash, GNU make, MSYS Perl)

Required — MinGW / ReactOS only

OpenSSL's MinGW/ReactOS build uses MSYS2 bash.exe, GNU make, and MSYS Perl (not Strawberry Perl).

Open MSYS2 Download Page
  1. Under Installation on the MSYS2 homepage, click Download the installer (msys2-x86_64-*.exe).
  2. Install to the default directory (C:\msys64).
  3. Open the MSYS2 terminal and install GNU make and Perl if not already present: pacman -S make perl.

Checked by CMake: bash.exe in PATH or C:/msys64/usr/bin.
