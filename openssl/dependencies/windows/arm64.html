OpenSSL — Windows ARM64 Build Dependencies

Host tools checked by port/external_build/openssl/CMakeLists.txt when building OpenSSL for Windows ARM64.

x64 ARM64

Native Windows Perl (Strawberry Perl)

Required — MSVC ARM64

OpenSSL's MSVC configure script requires a native Windows Perl ($^O == MSWin32). Strawberry Perl does not publish a separate ARM64 MSI; the 64-bit (x64) MSI runs under Windows 11 ARM64 emulation and is supported for configuring OpenSSL ARM64 builds. MSYS2 or Git Bash Perl will not work for MSVC builds.

Open Strawberry Perl Download Page
  1. On the Strawberry Perl homepage, choose the Recommended version — 64-bit MSI installer (.msi, not the Portable ZIP).
  2. Run the MSI installer using the default destination directory (C:\Strawberry\).
  3. Restart Visual Studio or your build terminal if PATH was updated, then rebuild.

Checked by CMake: perl.exe in PATH or C:/Strawberry/perl/bin, and perl -e "print $^O" returning MSWin32.

NMake & MSVC ARM64 Build Tools (Visual Studio)

Required — MSVC ARM64

OpenSSL's MSVC ARM64 build requires nmake.exe and the Visual Studio MSVC ARM64 toolchain (native vcvarsall.bat arm64 on ARM64 hosts, or cross-compile vcvarsall.bat amd64_arm64 on x64 hosts).

Open Visual Studio Downloads
  1. Download Visual Studio (Community/Pro/Enterprise) or scroll to Tools for Visual Studio → Build Tools for Visual Studio.
  2. In Visual Studio Installer, enable the Desktop development with C++ workload.
  3. Under Individual components, also select MSVC v14x - VS C++ ARM64/ARM64EC build tools (Latest).

Checked by CMake: nmake.exe available inside the Visual Studio ARM64 vcvarsall.bat environment.

NASM Assembler (Not used for ARM64 assembly)

Not required for ARM64

OpenSSL ARM64 assembly uses MSVC's armasm64.exe (included with the MSVC ARM64 build tools), not NASM. However, if -DOPENSSL_ASM=ON is passed, the current CMake check also looks for nasm.exe.

Open NASM Download Page
  1. Leave OPENSSL_ASM=OFF (the default) unless you specifically need assembly enabled.
  2. If nasm.exe is required by your CMake options, open Download → latest stable → win64/ and install nasm-*-installer-x64.exe on PATH.

Checked by CMake: nasm.exe in PATH only when OPENSSL_ASM is enabled.
